# Estilo de redacción

- Español profesional con tildes, `ñ` y signos de apertura. Nunca degradar a ASCII.
- Frases cortas en voz activa: "El sistema registra...", "Se propone...", "Se requiere confirmar...".
- Fórmulas recomendadas: `La evidencia indica...`, `Se propone...`, `A falta de confirmación...`, `Condicionado a...`.
- Evita: "solución robusta y escalable", "de vanguardia", "sinergias", "como modelo de lenguaje", "a continuación generaré".
- Tablas para inventarios, matrices y comparativas; prosa para contexto y razonamiento.
- Backticks para sistemas, campos, endpoints, operaciones, tablas, ficheros y servicios.
- Mermaid: `flowchart LR` o `erDiagram` sencillos; etiquetas cortas; sin estilos complejos.
- Un documento `client-ready` explica utilidad y frontera de alcance, nunca el proceso de redacción.
